# FOCUS

Личный планировщик для важных задач и проектов на React и TypeScript
с собственным адаптивным интерфейсом, локальной графикой и хранением данных
в браузере.

**[Открыть FOCUS](https://todo.almistech.ru)**

## Возможности

- Главный экран «Мой день»: настоящий план, следующий шаг, требующие внимания
  задачи и состояние проектов. Пример пространства добавляется только по кнопке.
- Проекты с цветами: создание, переименование и удаление с переносом задач во
  «Входящие». Задачи при удалении проекта сохраняются.
- Задачи с заметками, сроками и приоритетами; шаги с отдельными флажками и прогрессом.
- Завершение задачи завершает её шаги. Незавершённый шаг снова открывает задачу;
  полностью готовый чеклист можно завершить отдельно с главного экрана.
- Отметка фокуса на сегодня сохраняет настоящий срок. «Мой день» объединяет
  текущий фокус, сегодняшние и просроченные невыполненные задачи.
- Просторные окна создания и редактирования: многострочные название и описание,
  шаги, сроки, проект и файлы. Кнопка создания сразу открывает окно.
- Ctrl/Cmd Enter сохраняет задачу; Enter добавляет шаг. Последний набранный шаг
  сохраняется вместе с задачей даже без отдельного нажатия «плюс».
- Подтверждение закрытия черновика, управляемый фокус и неподвижный фон.
  На телефоне поля и действия находятся в отдельных областях прокрутки.
- Календарь месяца, список дня и нагрузка на ближайшую неделю; проектный календарь.
- Быстрые сроки, поиск по названиям/заметкам/шагам, сортировка, групповые действия
  и отмена удаления/переноса. Очистка готового ограничена видимым списком.
- Ссылки на проекты и разделы восстанавливают контекст после обновления страницы.
- Общий поиск по всему пространству через Ctrl/Cmd K, быстрые переходы и
  создание задачи; массовый перенос между проектами с безопасной отменой.
- Вложения любого формата: до 10 МБ на файл, 50 МБ и 100 файлов в пространстве.
  Изображения и текст просматриваются внутри сайта, PDF — в просмотрщике
  браузера; остальные форматы скачиваются для открытия в своём приложении.
- Библиотека файлов с поиском. Удаление задачи сохраняет её вложения в библиотеке;
  отдельный файл удаляется навсегда только после подтверждения.
- Полный локальный JSON export/import проектов, задач и файлов, preview и
  объединение по ID. Прежние копии по-прежнему читаются.
- Web Locks и единый журнал намерений защищают транзакции проектов/задач между вкладками.
- Валидация, полная резервная копия при миграции и явное восстановление повреждённых
  данных. При отказе записи изменения остаются в памяти с предупреждением.
- Нативные доступные элементы, управляемая клавиатура и уменьшенная анимация.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci --ignore-scripts
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Зависимости закреплены в package-lock.json. Бизнес-логика и storage проверяются
79 тестами через встроенный `node:test`, без отдельного тестового фреймворка.

## Структура

```text
src/domain/       модель задач, операции, поиск и валидация
src/storage/      версионированное хранилище и восстановление
src/hooks/        состояние и синхронизация с браузером
src/components/   элементы интерфейса
src/App.tsx       сборка пользовательского сценария
public/           локальные изображения, шрифты и лицензия
tests/            проверки пользовательских правил и отказов хранения
```

## Данные и безопасность

У приложения нет бэкенда, регистрации, аналитики и сетевой отправки задач.
Задачи находятся в localStorage, файлы — в IndexedDB конкретного браузера и
origin. Это не облачное хранилище: очистка данных браузера удалит список и файлы. Не используйте
его для секретов. JSON-копия содержит задачи и заметки: храните её как личный файл.
Импорт обрабатывается локально, файл никуда не загружается. Современный браузер с Web Locks защищает запись между вкладками. Без этой
возможности изменения остаются в памяти с явным предупреждением. Это
локальный список, а не облачная многопользовательская система.

Текст задач отображается средствами React как текст; HTML из ввода не
исполняется. Формат данных проверяется до отображения. Сбой записи не
превращается в ложное сообщение об успешном сохранении. Production-развёртывание
использует HTTPS и ограничивающие HTTP-заголовки; в репозитории нет ключей
или приватной переписки.

Формат v3 хранит проекты и задачи в одном документе и читает старые v1/v2.
Перед первой записью v3 исходные данные полностью сохраняются в локальную
копию before-v3; ошибка копирования не заменяет оригинал. Старые вкладки
следует обновить: прежний код не понимает v3 и не должен восстанавливать его
поверх новой версии. Данные v1/v2 остаются задачами во «Входящих».

## Вложения и полная копия

Файлы не отправляются на сервер и не открываются внешними онлайн-сервисами.
HTML/SVG и код показываются как текст, растровые изображения рисуются на canvas.
Для скачивания используется бинарный MIME; PDF открывается отдельно штатным
просмотрщиком браузера. В существующей задаче вложения сохраняются сразу.
В окне создания файлы прикрепляются после создания задачи; при отказе записи
можно повторить прикрепление без дубликата задачи. Черновик остаётся в окне.

Полная копия использует формат v4 с файлами; формат сохранённых задач остаётся v3.
При недоступном хранилище файлов интерфейс явно предлагает копию без вложений.
Задачи и файлы используют разные хранилища: если запись файлов при импорте
не удалась, уже добавленные задачи остаются, а подтверждение сохраняется для
повторной попытки. Совпавшие ID не заменяются. Копия содержит личные данные:
храните её как личный файл. Включены также вложения удалённых задач.

## Продуктовые ориентиры

Изучены [планирование Todoist](https://www.todoist.com/help/todoist/features/schedule-a-date-and-time-for-your-todoist-tasks-q7VobO)
и [обзор будущих дел Things](https://culturedcode.com/things/support/articles/4001304/).

платные API не используются, внешние календарные аккаунты не подключаются.

Дополнительно изучены [организация проектов Things](https://culturedcode.com/things/support/articles/6378414/),
[шаги Microsoft To Do](https://support.microsoft.com/en-us/todo/add-steps-importance-notes-tags-and-categories-to-your-tasks)
и [разделы Todoist](https://www.todoist.com/help/todoist/features/introduction-to-sections-rOrK0aEn).
Сравнение помогло улучшить сценарий целиком: от выбора главного дела до проекта,
шагов и календаря. Внешний код и новые зависимости для этого не добавлялись.
