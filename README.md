# FOCUS

Личный планировщик на React и TypeScript. Задачи, проекты, календарь и файлы
в одном спокойном рабочем пространстве.

**[Открыть сайт](https://todo.almistech.ru)**

## Что умеет

- «Мой день», входящие и проекты; список, доска со статусами, карточки в две
  или три колонки и календарь. На узком экране карточки идут в одну колонку.
- Быстрое добавление и полноценный редактор: заметки, шаги, приоритет, срок,
  теги и ежедневное или еженедельное повторение.
- Поиск по задачам, заметкам, шагам и тегам; общий поиск через Ctrl / ⌘ K.
- Групповые действия, перенос между проектами и отмена удаления или переноса.
- Рабочее окно задачи: шаги, комментарии и файлы к каждому шагу,
  текстовые таблицы и рисование схем. Выполнение шага не закрывает окно.
- Фокус-таймер с круговым отсчётом, паузой, историей, дневной целью
  и своей длительностью работы и перерыва.
- Светлая, тёмная, зелёная и системная темы; настройка плотности интерфейса.
- Вложения любого формата, до 100 файлов. Размер ограничен местом и возможностями
  браузера и устройства; перед записью проверяется доступная квота.
  Внутри сайта: текст, CSV/TSV, растровые изображения, PDF, поддерживаемые
  браузером аудио и видео, упрощённый текст DOCX/XLSX/PPTX и список файлов ZIP.
  Остальные форматы скачиваются для открытия в подходящей программе.
- Полная копия задач, проектов, файлов, журнала, настроек и истории фокуса:
  JSON для небольших данных, ZIP без base64 для больших вложений.
  Перед импортом показывается состав копии; совпадающие ID сохраняются.
- Офлайн-работа после загрузки оболочки; установка как PWA в поддерживаемом
  браузере. Обновление приложения учитывает открытые окна и черновики.
- Готовый пример с шестью задачами, тремя проектами и шестью тестовыми
  файлами добавляется по желанию. Примеры файлов можно посмотреть в библиотеке
  без добавления в свои данные.

## Запуск

Node.js **22.13+**, современный браузер с Web Locks.

```sh
npm ci --ignore-scripts
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Зависимости закреплены в lock-файле. 118 тестов на встроенном `node:test`
проверяют модель, миграции, повторения, таймер, копии, конфликты и отказы
хранилища. Дополнительно проверены пользовательские сценарии в браузере:
две вкладки, офлайн-обновления, файлы, клавиатура и экраны 320–1440 px.

Для предпросмотра есть отдельные ограничения: текст и CSV — первые 200 КБ,
таблицы — до 200 строк и 30 колонок; PDF, изображения и Office/ZIP — до 32 МБ.
Office показывает только текст и значения, без исходного макета и вычисления
формул. Оригинал сохраняется целиком. Поддержка медиакодеков зависит от браузера.
Многогигабайтные файлы и физические телефоны отдельно не проверялись.

## Устройство проекта

| Каталог           | Ответственность                                                  |
| ----------------- | ---------------------------------------------------------------- |
| `src/domain/`     | Правила задач, проектов, повторений, поиска и таймера            |
| `src/storage/`    | Валидация, сохранение, журнал намерений, импорт и восстановление |
| `src/hooks/`      | Контроллеры сценариев, синхронизация и состояние интерфейса      |
| `src/components/` | Формы, навигация, календарь, доска и просмотр файлов             |
| `build/`          | Генерация офлайн-оболочки и политика заголовков                  |
| `public/`         | Собственная графика, иконки, локальные шрифты и лицензии         |
| `tests/`          | Проверки правил и устойчивости данных                            |

`App.tsx` соединяет сценарии и навигацию. Подробные границы модулей и
правила изменений — в [PROJECT_MAP.md](PROJECT_MAP.md).

## Данные и безопасность

Приложение статическое: без регистрации, аналитики и отправки задач или
файлов на сервер. Задачи и настройки хранятся в localStorage, файлы —
в IndexedDB этого браузера и адреса сайта. Устройства автоматически
не синхронизируются. Перед очисткой браузера скачайте полную копию.

Запись задач между вкладками сериализуется через Web Locks, несохранённые
операции повторяются поверх актуального состояния. Ошибки записи видимы.
Формат задач v4 отделён от прежнего ключа; исходные данные полностью
копируются перед миграцией. Запись из старой вкладки сохраняется отдельной
веткой с предупреждением. Формат полной копии v5 читает прежние копии.

Восстановление повреждённого хранилища требует действия пользователя и
успешного сохранения исходных байтов. Удаление задачи оставляет её файлы
в библиотеке; окончательное удаление файла требует подтверждения.

Пользовательский текст выводится как текст. HTML/SVG и код не исполняются.
PDF.js рисует PDF локально на canvas, без внешнего просмотрщика, форм и
активных аннотаций. Размеры предпросмотра и извлечения текста ограничены.
Неподдерживаемый формат доступен для скачивания.

Публикация использует HTTPS и ограничивающую CSP. Зависимости и публичные
артефакты проверены; это не гарантия отсутствия всех уязвимостей.
Копии содержат личные данные: храните их соответственно.
