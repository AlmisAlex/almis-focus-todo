# FOCUS

Личное пространство для важных задач. Небольшой To-Do на React и TypeScript
с собственным адаптивным интерфейсом, локальной графикой и хранением данных
в браузере.

**[Открыть FOCUS](https://todo.almistech.ru)**

## Возможности

- Добавление, завершение, возврат в работу и удаление задач.
- Редактирование названия и заметки, срок и три уровня приоритета.
- Сохранение после обновления страницы, поиск по названиям и заметкам.
- Разделы «Сегодня» и «Просрочено», сортировка по сроку/приоритету/созданию.
- Групповые завершение, возврат и удаление; отмена удаления.
- Экспорт JSON и импорт с предварительным просмотром и объединением по ID.
- Примеры по отдельной кнопке; компактный адаптивный workspace.
- Enter добавляет, Alt+N переводит фокус на ввод, Alt+/ — на поиск.
- Модальный редактор подтверждает закрытие несохранённого черновика.
- Валидация данных, обработка отказов storage и восстановление полной копии.
- Web Locks и replay несохранённых действий защищают запись между вкладками.
- Уменьшенная анимация и нативные доступные элементы управления.

## Запуск

Требуется Node.js 22.12 или новее.

```sh
npm ci --ignore-scripts
npm run dev
```

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

Зависимости закреплены в package-lock.json. Бизнес-логика и storage проверяются
32 тестами через встроенный `node:test`, без отдельного тестового фреймворка.

## Структура

```text
src/domain/       модель задач, операции, поиск и валидация
src/storage/      версионированное хранилище и восстановление
src/hooks/        состояние и синхронизация с браузером
src/components/   элементы интерфейса
src/App.tsx       сборка пользовательского сценария
public/           локальные изображения, шрифты и лицензия
tests/            проверки пользовательских правил и отказов хранения
```

## Данные и безопасность

У приложения нет бэкенда, регистрации, аналитики и сетевой отправки задач.
Данные находятся в localStorage конкретного браузера и origin. Это не
облачное хранилище: очистка данных браузера удалит список. Не используйте
его для секретов. JSON-копия содержит задачи и заметки: храните её как личный файл.
Импорт обрабатывается локально, файл никуда не загружается. Современный браузер с Web Locks защищает запись между вкладками. Без этой
возможности изменения остаются в памяти с явным предупреждением. Это
локальный список, а не облачная многопользовательская система.

Текст задач отображается средствами React как текст; HTML из ввода не
исполняется. Формат данных проверяется до отображения. Сбой записи не
превращается в ложное сообщение об успешном сохранении. Production-развёртывание
использует HTTPS и ограничивающие HTTP-заголовки; в репозитории нет ключей
или приватной переписки.

Формат v2 читает старые задачи v1. Перед первой записью v2 исходный список v1
сохраняется целиком; если резервирование не удалось, оригинал не заменяется.
После обновления сайта перезагрузите старые вкладки: прежняя версия не понимает
новый формат; не восстанавливайте сохранение в старой версии поверх новой.
